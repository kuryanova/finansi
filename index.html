Синхронизация — Supabase

По умолчанию данные сохраняются только на этом устройстве (localStorage). Для синхронизации между устройствами подключи свой проект Supabase: открой код страницы и впиши значения в блок SUPABASE_CONFIG.

Что нужно сделать:
1. Создай проект на supabase.com
2. Создай таблицу finance_data с полями: id (text, primary), data (jsonb), updated_at (timestamp)
3. Скопируй URL проекта и anon-ключ в код (см. блок SUPABASE_CONFIG)
4. Перезагрузи страницу
